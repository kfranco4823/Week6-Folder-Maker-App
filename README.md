# Week 6 Folder Maker App

## Purpose
My app creates an all in one simple solution to allow members of the bracer guild to see and accept
missions in different branches all with the click of a button without needing to return back to 
the main guild to accept the missions as well as see payment information easily. 

## How To Run
In VB.NET once the code has been completed and verified. Simply hit the green run button right at
the top and from their a command prompt will open where you will now direct your attention to.
